還在用收費的 IDM？這款開源免費、體積僅 20MB 的下載神器——Rayburst 絕對不容錯過！

發布於 2026-10-14 · 作者：夸諾 · 分類：系統優化工具

大大家好，作為一個合格的老司機，每天都要下載各類資源。如果你還在使用收費的 IDM，不如來看看今天這款知名的開源免費多執行緒下載神器——Rayburst（原名 Motrix Next）。

一、 官方倉庫與下載地址

你可以透過下方按鈕前往 GitHub 官方倉庫下載源碼，或者透過百度網盤獲取打包好的分發版本：

GitHub 官方原項目下載 百度網盤高速分發 (提取碼: nz25)

二、 軟體核心功能簡介

1.🚀 協議全能：老司機的終極利器

作為老司機神器，Rayburst 的協議支持非常全能！底層搭載了 Aria2 Next 引擎，HTTP、FTP、SFTP，甚至是古老的 ED2K 電驢協議通通不在話下。

而在 BitTorrent 磁力下載方面，它更是直接換上了 qBittorrent 同款的 libtorrent 專業內核！DHT、PEX 調度能力極強，磁力解析飛快，支持離線元數據感知和選擇性檔案下載，速度直接拉滿！

2.🎬 黑科技拉滿：原生串流媒體與直播錄製

更狠的是 v4.0 推出的原生串流媒體下載功能！

以往下載網頁串流媒體需要配置繁瑣的 ffmpeg，而 Rayburst 能直接讀取 HLS 和 MPEG-DASH 源，讓你自由選擇音視訊軌道和字幕，一鍵合成為標準的 MP4 或 MKV 檔案！

它甚至還支持網路直播錄製，設定好時間就能自動保存串流媒體檔案！

3.🌐 瀏覽器無縫聯動：Rayburst Connect

搭配官方瀏覽器外掛 Rayburst Connect，還能實現網頁資源自動嗅探和批次接管，體驗完全不遜色於 IDM。

⚠️ 避坑指南：瀏覽器外掛不能單獨使用！必須先到 Rayburst 桌面端軟體的設定裡找到 API 金鑰，複製並貼上到外掛的設定裡，否則外掛是無法正常運作的（會提示連線逾時）。

4.⚡ 極致輕量：體積暴減 75%，啟動秒開

在電腦資源佔用方面，Rayburst 拋棄了臃腫的 Electron 框架，改用 Tauri 2 + Rust 重寫。

安裝包體積從原本 Motrix 的 80MB 暴減 75%，現在只有 20MB 左右！啟動秒開，記憶體佔用幾乎沒有。

搭配 Material Design 3 風格的現代化 UI，動效極其絲滑，顏值相當能打。

5.🔒 安全與注意事項

軟體支持 Windows、macOS 和 Linux。

· 安裝提示：由於軟體沒有數位簽章，第一次安裝時系統可能會提示安全攔截，這完全屬於正常現象（放心放行即可）。

· 開源透明：軟體 100% 完全開源，採用 MIT 協議，零廣告、零遙測，配置歷史全存本地，完全不用擔心有任何後門。

三、 總結

如果你也在找一款輕量、全能、乾淨的下載工具，Rayburst 絕對不容錯過，一次性幫你把愛看的資源一網打盡。

如果有其他疑問，歡迎在 YouTube 影片下方留言討論！
